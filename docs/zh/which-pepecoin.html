如何区分各种 Pepecoin？

有三种不同的加密资产都以某种形式使用 Pepecoin 这个名称，Kraken 上线了全部三种。其中只有一种是运行在自有工作量证明链上的币。下文是一份附有来源的对比，涵盖冻结和公开身份——不作夸大宣传。

谁能冻结什么

PEP（本链）：协议中没有任何管理员密钥可以将你的地址列入黑名单，或阻止一笔已签名的转账。这与 Bitcoin 和 Dogecoin 的模式相同。但这并不意味着你不会损失币——转错网络、网络钓鱼或托管方冻结充币，这些风险依然存在。

PEPE（Ethereum 代币）：已验证的合约包含黑名单逻辑。上线前后，一个大量买入的地址被列入黑名单；随后所有权被放弃，因此通过 Ownable 进行的、仅限所有者的后续黑名单变更已无法生效。已被列入黑名单的余额仍被锁定。许多其他 ERC-20 代币保留着拥有暂停/黑名单权限的活跃所有者——务必阅读合约。

来源：Etherscan 上的 PEPE 合约 0x6982508145454Ce325dDbE47a25d4ec3d2311933；同期关于 2023年黑名单及放弃所有权交易的报道；Pepecoin Core 的 UTXO 设计。

常见问题

Pepecoin（PEP）就是 PEPE 吗？

不是。PEPE 是 Ethereum 上的 ERC-20 代币。Pepecoin（PEP）是运行在自有 Scrypt 工作量证明区块链上的原生币。请检查地址前缀：P… 与 0x…。

我需要什么钱包？

PEP 需要支持 Pepecoin 网络的钱包：官方的 Pepecoin Core、Tangem 卡，或本站钱包指南中的其他钱包。PEPE 和 PEPECOIN 是 Ethereum 代币，因此存放在 MetaMask 等 Ethereum 钱包中；MetaMask 专为 Ethereum 类网络打造，并未列出 Pepecoin。

有人能在协议层冻结我的 PEP 吗？

协议层没有管理员黑名单。托管方（交易所、托管钱包）仍可冻结其持有的余额。PEPE 的 Ethereum 合约则是另一回事——见上文“谁能冻结什么”。

为什么 Kraken 可能显示地区限制？

这是交易所政策和监管（包括欧洲经济区的 MiCA）所致，而非 Pepecoin 的共识规则。

提币时如何核对交易代码？

选择 Pepecoin 网络上的 Pepecoin（PEP）。PEP 地址以 P 开头。PEPE 和 PEPECOIN 是 Ethereum 代币，其地址以 0x 开头，属于另一个网络。见上文的地址核对。

如果转错网络怎么办？

转错网络通常无法挽回。Pepecoin 链上的 PEP 与 Ethereum 上的 PEPE 不可互换。发送前务必核对交易代码、网络和地址格式。PEP 转账可在 PepeBlocks 或 Pepeplorer 上查看；Ethereum 代币可在 Etherscan 上查看。

为什么 CoinMarketCap 显示的供应量可能与区块浏览器不同？

Pepeplorer 等区块浏览器显示为约 1048 亿 PEP。部分聚合平台仍显示约 1029 亿——请优先参考注明日期的实时区块浏览器。见上文“Pepecoin（PEP）数据一览”。

富豪榜上的一个地址就等于一个人吗？

不是。地址不等于个人：交易所和托管方为众多用户持有币。见富豪榜中的说明。
