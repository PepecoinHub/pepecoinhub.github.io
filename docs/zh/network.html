数据从哪里来

每天一个 GitHub Actions 任务向 PepeBlocks 浏览器和 pepecoinservice.org API 查询区块高度、供应量和富豪榜，并把结果保存到本站的代码库中。

2026年10月5日之前的数据是通过从第一个区块开始重放 Pepecoin 区块链重建的：2025年9月之前每周一个数据点，之后每天一个。

出块时间是两次快照之间的时间除以期间找到的区块数。地址指持有超过零 PEP 的地址；一个人可以使用很多地址，交易所也会替很多人保管币。
