钱包如何保管你的 PEP

币在区块链上，而不在应用里。钱包保管着能花费这些币的私钥，并显示从链上读取的余额。

关键在于备份。大多数钱包会提供助记词或可导出的备份。有了它，就能在另一个钱包中恢复同样的币。

交易所账户则不同。在交易所，密钥由交易所代你保管。将 PEP 提币到自己的钱包，密钥就掌握在你手中。如何提币。

常见问题

可以把 PEP 存放在 MetaMask 中吗？

不可以。MetaMask 专为 Ethereum 类网络打造，Pepecoin 也不在它支持的其他网络之列。PEP 需要支持 Pepecoin 网络的钱包。MetaMask 属于存放 PEPE 和 PEPECOIN 这类 Ethereum 代币的钱包。

什么是 Pepecoin Tangem 卡？

一款采用 Pepecoin 设计的 Tangem 联名冷钱包（2025 版），在官方 Pepecoin Shop 出售。它的用法与其他 Tangem 卡相同：密钥保存在卡内，配合 Tangem 应用使用。

必须运行 Pepecoin Core 吗？

不必。Pepecoin Core 是官方钱包，也是全节点，运行它对网络也有帮助；不过卡片钱包和移动钱包同样可以存放 PEP。

从哪里安全下载 Pepecoin Core？

从 pepecoinppc/pepecoin 的官方 GitHub 发布页面下载。优先使用这一来源，而非第三方镜像。
