钱包如何保管你的 PEP

币在区块链上，不在应用里。钱包保管的是能花掉这些币的私钥，并把从链上读取的余额显示给你。

备份才是关键。大多数钱包会给你一组助记词（recovery phrase），或者提供可导出的备份。有了它，就可以在另一个钱包里恢复出同样的币。

交易所账户则不一样。在交易所里，密钥由交易所替你保管；把 PEP 提到自己的钱包，密钥才真正握在你手里。如何提币。

常见问题

PEP 可以存在 MetaMask 里吗？

不可以。MetaMask 是为 Ethereum 类网络设计的，它支持的其他网络里也没有 Pepecoin。存放 PEP 需要支持 Pepecoin 网络的钱包。MetaMask 这类钱包适合存放 PEPE 和 PEPECOIN，它们都是 Ethereum 代币。

什么是 Pepecoin Tangem 卡？

Tangem 与 Pepecoin 联名推出的冷钱包，采用 Pepecoin 设计（2025 版），在官方 Pepecoin Shop 出售。它和其他 Tangem 卡用法一样：密钥保存在卡里，配合 Tangem 应用使用。

必须运行 Pepecoin Core 吗？

不必。Pepecoin Core 是官方钱包，同时也是全节点，运行它对网络也有帮助；不过卡片钱包和移动端钱包同样可以存放 PEP。

从哪里安全下载 Pepecoin Core？

请从 pepecoinppc/pepecoin 的官方 GitHub 发布页面下载，并优先使用这个来源，而不是第三方镜像。
