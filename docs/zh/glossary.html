Pepecoin 术语表

工作量证明（proof of work）
靠计算工作来保障安全：矿工竞相找出下一个区块，而要改写历史，就得把这些工作重做一遍。Scrypt 家族 →
公平启动（fair launch）
没有预挖、预售和团队份额的启动方式，每一枚币都来自挖矿。PEP 就是这样启动的。如何区分 →
合并挖矿（AuxPoW）
AuxPoW 即辅助工作量证明（auxiliary proof of work）：同一份挖矿工作在多条使用相同算法的链上都有效，每条链各自发放奖励。PEP 自区块高度 42,000 起，一直与 Litecoin（莱特币）和 Dogecoin（狗狗币）采用这一机制。Scrypt 家族 →
减半（halving）
区块奖励削减一半。PEP 的奖励每 100,000 个区块减半一次，直到区块高度 600,000，此后一直保持在 10,000。供应量与通胀 →
矿池（mining pool）
矿工们把各自的挖矿工作合在一起，并共同分享奖励的服务。如何挖 PEP →
冷钱包（cold wallet）
密钥不放在联网电脑上的钱包，例如 Tangem 卡。PEP 钱包 →
区块（block）
一批被打包并添加到链上的交易。Pepecoin 的目标是每 60 秒出一个区块。网络统计 →
区块奖励（block reward）
发放给挖出区块者的新币。自区块高度 600,000 起，每个区块 10,000 PEP。供应量与通胀 →
区块浏览器（block explorer）
用来查看区块、交易和地址余额的网站。查询 PEP 可以用 PepeBlocks 或 Pepeplorer。如何购买 PEP →
全节点（full node）
自己下载并验证每一个区块的软件，例如 Pepecoin Core。PEP 钱包 →
市值（market cap）
价格乘以供应量，常用来比较两种币的规模。PEP 与 DOGE →
算力（hashrate）
整条链上用于挖矿的总计算能力，单位是每秒哈希数。PEP 在 2026年10月的算力约为 2.9 PH/s。算力对比 →
通胀率（inflation rate）
每年新增的币量除以现有币量。PEP 在 2026年约为 5%，并逐年下降。供应量与通胀 →
托管（custodial）
密钥和币由别人（通常是交易所）替你保管。PEP 钱包 →
挖矿难度（difficulty）
找到一个有效区块有多难。它会不断调整，使区块大约保持每分钟出一个。算力对比 →
预挖（premine）
项目启动时，在正常挖矿之外预先为内部人士创建的币。PEP 没有预挖。如何区分 →
助记词（recovery phrase）
用来备份钱包密钥的一组单词。谁掌握了它，谁就能花掉这些币。PEP 钱包 →
ERC-20
Ethereum（以太坊）上的代币标准。PEPE 和 PEPECOIN 是 ERC-20 代币，PEP 不是。如何区分 →
Scrypt
Litecoin、Dogecoin 和 Pepecoin 采用的哈希函数，由 Colin Percival 于 2009年发布。它比 Bitcoin（比特币）使用的 SHA-256 需要更多内存。Scrypt 家族 →
UTXO
UTXO 即未花费交易输出（unspent transaction output）。币以一个个输出的形式存在，每个输出只能花费一次。Bitcoin、Dogecoin 和 Pepecoin 都是这种方式，而 Ethereum 代币记录的是余额。如何区分 →
