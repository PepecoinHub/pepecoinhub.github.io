Pepecoin 术语表

围绕 PEP 反复出现的术语，每个用一两句话解释，并附上本站深入介绍该话题的页面链接。

术语

AuxPoW Block Block explorer Block reward Cold wallet Custodial Difficulty ERC-20 Fair launch Full node Halving Hashrate Inflation rate Market cap Mining pool Premine Proof of work Recovery phrase Scrypt UTXO
AuxPoW (merged mining) – 合并挖矿
辅助工作量证明。同一份挖矿工作在使用相同算法的多条链上都有效，每条链各自支付奖励。PEP 自区块高度 42,000 起与 Litecoin（莱特币）和 Dogecoin（狗狗币）一起使用这一机制。Scrypt 家族 →
Block – 区块
添加到链上的一批交易。Pepecoin 的目标是每 60 秒产生一个区块。网络统计 →
Block explorer – 区块浏览器
显示区块、交易和地址余额的网站，例如 PEP 的 PepeBlocks 或 Pepeplorer。如何购买 PEP →
Block reward – 区块奖励
支付给挖出区块者的新币。自区块高度 600,000 起为 10,000 PEP。供应量与通胀 →
Cold wallet – 冷钱包
密钥不存放在联网计算机上的钱包，例如 Tangem 卡。PEP 钱包 →
Custodial – 托管
由他人（通常是交易所）代你保管密钥和币。PEP 钱包 →
Difficulty – 难度
找到一个有效区块的难易程度。它会相应调整，使区块保持大约每分钟产生一个。算力对比 →
ERC-20
Ethereum（以太坊）上的代币标准。PEPE 和 PEPECOIN 是 ERC-20 代币；PEP 不是。如何区分 →
Fair launch – 公平启动
没有预挖、预售或团队分配的启动方式，每一枚币都来自挖矿。PEP 就是以这种方式启动的。如何区分 →
Full node – 全节点
自行下载并验证每个区块的软件，例如 Pepecoin Core。PEP 钱包 →
Halving – 减半
将区块奖励削减一半。PEP 的奖励每 100,000 个区块减半一次，直到区块高度 600,000，此后一直保持在 10,000。供应量与通胀 →
Hashrate – 算力
投入某条链挖矿的总计算能力，单位为每秒哈希数。2026年10月，PEP 的算力约为 2.9 PH/s。算力对比 →
Inflation rate – 通胀率
每年新增币量除以现有币量。PEP 在 2026年约为 5%，并逐年下降。供应量与通胀 →
Market cap – 市值
价格乘以供应量。可用于比较两种币的规模。PEP 与 DOGE →
Mining pool – 矿池
许多矿工汇集挖矿工作并分享奖励的服务。如何挖 PEP →
Premine – 预挖
启动时在正常挖矿之外为内部人士创建的币。PEP 没有预挖。如何区分 →
Proof of work – 工作量证明
通过计算工作保障安全：矿工竞相找出下一个区块，而改写历史就意味着要重做这些工作。Scrypt 家族 →
Recovery phrase – 助记词
用于备份钱包密钥的一组单词。谁拥有它，谁就能花费这些币。PEP 钱包 →
Scrypt
Litecoin、Dogecoin 和 Pepecoin 所用的哈希函数，由 Colin Percival 于 2009年发布。它比 Bitcoin（比特币）的 SHA-256 需要更多内存。Scrypt 家族 →
UTXO
未花费的交易输出。币以输出的形式存在，每个输出只能花费一次。Bitcoin、Dogecoin 和 Pepecoin 都采用这种方式；Ethereum 代币则记录余额。如何区分 →
