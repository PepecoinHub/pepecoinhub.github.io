挖矿指南

如何挖 Pepecoin (PEP)

PEP 使用 Scrypt 挖矿，与 Litecoin 和 Dogecoin 采用相同的工作量证明。大部分 PEP 来自合并挖矿：Litecoin 矿池中的一台矿机，在获得 LTC 和 DOGE 的同时还能获得 PEP，所做的工作完全相同。

算法Scrypt与 LTC 和 DOGE 相同
区块奖励10,000 PEP自区块 600,000 起固定
目标出块时间60 s近期平均 62.6 秒
合并挖矿区块 42,000与 Litecoin 和 Dogecoin

分步操作

  1. 准备一台 Scrypt ASIC 矿机

    Scrypt 挖矿需要专用机器。ViaBTC 举的例子是 Antminer L9 和 ElphaPex DG1。

  2. 加入支持合并挖 PEP 的矿池

    在支付 LTC 和 DOGE 的同时也支付 PEP 的矿池包括 ViaBTC、F2Pool、Binance Pool、EMCD、AntPool、Mining-Dutch 和 KuPool。litecoinpool.org 也合并挖 PEP，但它把这部分价值以额外的 LTC 和 DOGE 支付（更高的 PPS 比率），而不是支付 PEP。实时列表见 miningpoolstats。

  3. 添加 PEP 收款地址

    任何 PEP 钱包都可以用作挖矿钱包：在矿池设置中填写它的收款地址，该地址以 P 开头。每个矿池都有自己的支付设置和最低支付额。以太坊地址（0x…）无法使用。获取 PEP 钱包。

  4. 把矿机连接到矿池

    使用矿池的 Scrypt (Litecoin) 连接地址。之后 PEP 奖励会和你的 LTC、DOGE 一起到账。

PEP 可以挖，PEPE 不能

⛏️ PEP 是唯一拥有真正挖矿网络的 Pepe 币：它与 Litecoin 和 Dogecoin 合并挖矿，全网算力约 1.9 PH/s。以太坊上的 Pepe 代币（PEPE、PEPECOIN）根本不挖矿。

搜索“Pepe 币挖矿”会出现三种不同的资产。其中只有 Pepecoin (PEP) 是通过挖矿产生的：它有自己的区块链，由 Scrypt 工作量证明保护。

Pepe (PEPE) 和 PepeCoin (PEPECOIN) 是以太坊上的 ERC-20 代币。以太坊已于 2022年9月15日用权益证明取代了挖矿，所以根本没有可挖的东西。声称可以“挖 PEPE”的应用或网站，并不是在任何区块链上挖它。

设置收款地址之前，请核对币种代码和网络：选择 Pepecoin 网络上的 PEP，地址以 P 开头。PEP、PEPE 和 PEPECOIN 并排对比。

支付 Pepecoin 的矿池

使用 Scrypt 矿机 (ASIC)，以下任一矿池都会在你挖 Litecoin 和 Dogecoin 时额外支付 PEP。使用 GPU 或 CPU，可通过 unMineable 获得 PEP。

💻 只有笔记本或游戏电脑？一样可以赚 PEP。

unMineable 让你用 CPU 或 GPU 挖矿，并以 Pepecoin 支付收益。下载它的挖矿软件，选择 Pepecoin 网络上的 PEP（不是以太坊上的 PEPE），再填入你的 PEP 地址。收益会很少：笔记本无法和 Scrypt ASIC 相比。

常见问题

可以用 GPU 或 CPU 挖 Pepecoin 吗？

不能直接在 Pepecoin 网络上挖，它由 Scrypt ASIC 矿机保护。但你可以通过 unMineable 用 GPU 或 CPU 赚取 PEP：它挖其他币，再以 Pepecoin (PEP) 支付给你。请选择 PEP 而不是 PEPE，并使用以 P 开头的地址。

哪些矿池支付 Pepecoin？

ViaBTC、F2Pool、Binance Pool、EMCD、AntPool、KuPool 和 Mining-Dutch 支付 PEP。litecoinpool.org 联合挖 PEP，但以额外的 LTC 和 DOGE 支付其价值。unMineable 向 GPU 和 CPU 矿工支付 PEP。实时列表见 miningpoolstats。

合并挖矿会减少我的 LTC 或 DOGE 收益吗？

不会。算力不会在各条链之间分摊。据矿池 ViaBTC 的说法，PEP 是合并挖矿带来的额外奖励，不需要额外算力。

用什么硬件挖 PEP？Antminer L7 或 L9 可以吗？

Scrypt ASIC 矿机，也就是挖 Litecoin 和 Dogecoin 的同一种机器。ViaBTC 举的例子是 Antminer L9 和 ElphaPex DG1。可以，Antminer L7 和 L9 都能挖 PEP：接入支持 Pepecoin 合并挖矿的矿池，就能在 LTC 和 DOGE 之外额外获得 PEP。

可以挖 Pepe (PEPE) 吗？

不能。Pepe (PEPE) 是以太坊上的 ERC-20 代币，而以太坊自 2022年9月15日起已用权益证明取代了挖矿。真正通过挖矿产生的是运行在自己区块链上的 Pepecoin (PEP)。

挖矿收益要用什么钱包接收？

任何能在 Pepecoin 网络上存放 Pepecoin (PEP) 的钱包都可以，例如 Pepecoin Core 或 Tangem 卡。它的收款地址以 P 开头。MetaMask 是为以太坊类网络设计的，其网络列表里没有 Pepecoin。

网络每天发放多少 PEP？

每个区块奖励 10,000 PEP。按每分钟一个区块的目标计算，每天最多 1440 万 PEP，由所有挖矿者分享。过去一年平均出块时间约 62.6 秒，因此实际数字约为 1380 万。
