如何购买 Pepecoin（PEP）

PEP 是 Pepecoin 区块链的原生币。大多数交易所提供 PEP/USDT 交易对，Kraken 还提供 PEP 兑美元和欧元的交易对。买币一共四步，最后 PEP 会放进由你自己掌控的钱包。

分步说明

  1. 选择交易平台

    选一家已上线 PEP 的交易所或闪兑（swap）服务，下方列出了一些。Kraken 上有三种名字里带 Pepe 的不同资产，PEP 是其中名为 Pepecoin、拥有独立区块链的那一种。如何区分它们。

  2. 充值并买入

    按交易所的规则充入法币或 USDT，然后在 PEP/USD、PEP/EUR 或 PEP/USDT 交易对上买入。

  3. 提币到自己的钱包

    在提币页面选择 Pepecoin 网络，粘贴你自己钱包的收款地址。PEP 地址以 P 开头。提币手续费和最低提币数量由交易所自己决定。该选哪种钱包。

  4. 在区块浏览器里确认

    把你的地址或交易 ID 粘贴到 PepeBlocks 或 Pepeplorer，查看确认进度。大约每分钟会出一个新区块。

常见问题

提 PEP 时该选哪个网络？

选 Pepecoin（PEP）。收款地址必须以 P 开头；以 0x 开头的是 Ethereum（以太坊）地址，属于另一个网络。提币时请选标为 Pepecoin / PEP 的资产，不要选 PEPE 或 PEPECOIN。

PEP 就是 PEPE 或 PEPECOIN 吗？

不是。PEPE 和 PEPECOIN 是 Ethereum 上的代币，PEP 则是拥有独立区块链的原生币。参见《如何区分三种 Pepecoin？》

把 PEP 提到 Ethereum 的 0x 地址会怎样？

发送到错误网络的转账通常无法撤销。PEP 只能转到以 P 开头的 Pepecoin 地址。转出后，可以在 PepeBlocks 或 Pepeplorer 上查看这笔转账。

可以用银行卡购买 PEP 吗？

pepecoin.com 上列出了 Alchemy Pay，可以用银行卡购买。各家交易所支持的充值方式不同，请以你所用交易所的说明为准。

提币需要多长时间？

Pepecoin 大约每分钟出一个区块。至于交易所要等多少个确认、多久处理提币，都由交易所自己决定。
