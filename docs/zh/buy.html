如何购买 Pepecoin（PEP）

PEP 是 Pepecoin 区块链的币。大多数交易所提供 PEP 与 USDT 的交易对，Kraken 还提供与美元和欧元的交易对。购买共分四步，最终 PEP 会存放在你掌控的钱包中。

分步说明

  1. 选择交易市场

    选择一家上线了 PEP 的交易所或闪兑服务，例如下方所列。Kraken 上有三种名称中带 Pepe 的不同资产：PEP 是名为 Pepecoin、拥有自有区块链的那一种。如何区分它们。

  2. 充值并买入

    按交易所自身的规则充值法币或 USDT，然后在 PEP/USD、PEP/EUR 或 PEP/USDT 市场买入。

  3. 提币到自己的钱包

    在提币页面选择 Pepecoin 网络，并粘贴你钱包中的收款地址。PEP 地址以 P 开头。提币手续费和最低提币数量由交易所自行设定。该用哪种钱包。

  4. 在区块浏览器中核对

    将你的地址或交易 ID 粘贴到 PepeBlocks 或 Pepeplorer，查看确认进度。大约每分钟产生一个新区块。

常见问题

PEP 提币时应选择哪个网络？

Pepecoin（PEP）。收款地址必须以 P 开头。以 0x 开头的地址属于 Ethereum（以太坊），这是另一个网络。在提币表单中，请选择标为 Pepecoin / PEP 的资产——不要选 PEPE 或 PEPECOIN。

PEP 就是 PEPE 或 PEPECOIN 吗？

不是。PEPE 和 PEPECOIN 是 Ethereum 上的代币。PEP 是其自有区块链的币。参见如何区分各种 Pepecoin？

如果把 PEP 提到 Ethereum 的 0x 地址会怎样？

转错网络通常无法挽回。PEP 必须发送到以 P 开头的 Pepecoin 地址。发送后，可在 PepeBlocks 或 Pepeplorer 上查看这笔转账。

可以用银行卡购买 PEP 吗？

pepecoin.com 列出了 Alchemy Pay，可用银行卡购买。各交易所自行设定充值方式，请查看你所用交易所的说明。

提币需要多长时间？

Pepecoin 大约每分钟产生一个区块。交易所要等待多少个确认、多快发出提币，由交易所自行决定。
