PEP 不是 PEPE

Pepecoin（PEP）运行在自己的区块链上，与 Litecoin 和 Dogecoin 合并挖矿。它与 Pepe（PEPE）和 PepeCoin（PEPECOIN）都不是一回事：Pepe 是 2023年推出的 Ethereum（以太坊）代币；PepeCoin 是 2016年的项目，2023年迁移到了 Ethereum。

  • PEPPepecoin独立的工作量证明区块链
  • PEPEPepeEthereum 上的 ERC-20 代币
  • PEPECOINPepeCoinEthereum 上的 ERC-20 代币

四步购买 PEP

  1. 第 1 步

    在 Kraken 开户

    在 PEP/USD 或 PEP/EUR 交易对买入。PEP 是拥有自己区块链的 Pepecoin，不是 PEPE。

  2. 第 2 步

    提币到自己的钱包

    买入后把 PEP 转到你自己的钱包（地址以 P 开头），妥善保管。

  3. 第 3 步

    也可以买一张 Tangem

    一张离线保存 PEP 的硬件卡。Pepecoin 官方商店有品牌联名 Tangem 卡出售。

  4. 第 4 步

    HODL，打个招呼

    来 Discord 或 r/pepecoin 逛逛，感受一下氛围。

四步挖 PEP

  1. 第 1 步

    准备一台 Scrypt ASIC 矿机

    和挖 Litecoin、Dogecoin 的是同一类矿机，例如 Antminer L9。

  2. 第 2 步

    加入支持合并挖 PEP 的矿池

    ViaBTC、F2Pool、Binance Pool 等矿池在 LTC 和 DOGE 之外额外支付 PEP。

  3. 第 3 步

    添加 PEP 收款地址

    以 P 开头的地址。以 0x 开头的以太坊地址不能用。

  4. 第 4 步

    把矿机连接到矿池

    使用矿池的 Scrypt 连接地址。PEP 会和 LTC、DOGE 一起到账。

关于 Pepecoin

什么是 Pepecoin？

Pepecoin（PEP）是一种开放的工作量证明币，运行在自己的区块链上。它是为 Pepe 而建的点对点网络，没有预挖，也没有单一的运营方。节点遵循一套公开的规则，任何人都可以运行节点。
