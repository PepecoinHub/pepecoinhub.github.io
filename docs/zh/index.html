关于 Pepecoin

什么是 Pepecoin？

Pepecoin（PEP）是运行在自有区块链上的开放式工作量证明币——一个属于 Pepe 的点对点网络，没有预挖，也没有单一运营方。节点遵循一套任何人都可以运行的公开规则。

三币同挖

通过合并挖矿（AuxPoW），Litecoin、Dogecoin 和 Pepecoin 可以基于同一份 Scrypt 工作量一同挖矿。
