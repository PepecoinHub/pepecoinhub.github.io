# Weapon art handoff — prototype only

Phase2 v11 was absent from the attachments during this work. No animation frames were invented or generated. The runtime still uses the existing SVGs as explicit flight placeholders, not HUD PNGs or Canvas rectangles. v10 PNGs are HUD only; the three original v10 FX sheets remain unchanged. They do not substitute for dedicated v11 flight/strike/explosion art.

`manifest.json` separates `flight`, `activation`, and `explosion` from HUD assets for every weapon (including child projectiles). Replace a null role with a validated PNG clip once v11 is available. Each clip specifies: `src` relative to games/, `frame` [source width,height], `columns`, `frames`, `fps`, `loop`, `anchor` [source x,y], and `size` [world width,height]. Frame size is deliberately not prescribed for missing v11. Validate actual alpha bounds, frame dimensions and orientation against its manifest before integration. All clip frames use a common source rectangle size within that clip. Source anchor maps exactly to the physical projectile position; render size never changes hitboxes or projectileOrigin. Doge/Moon face along velocity, thrown Foot/Bell spin unless reduced motion; explosion clips use the impact position. Mirror/orientation corrections must stay cosmetic.

Time comes from shot/trap age or the existing animator clock; no frame-count timers. Reduced motion picks a static frame. Pending FX clear on new match/restore and never enter game snapshots. A v10 impact sheet is a generic burst, not a footprint: the prototype footprint separately draws the existing gold.svg at impact for 1.8 seconds. Dedicated Mega flight and toe PNGs remain pending; current toe crops the existing gold.svg's large toe. Doge/Donkey SVG placeholders must not be marked as final animated PNG integration.

Map slots live in pondwars-weapon-art.mjs, in world coordinates. They draw behind terrain as faint distant backdrops, with a NO COLLISION label. They never read/write the destructible mask. Moon habitat/antenna, Doom gate/tree, Farm barn/windmill, Quarry crane/conveyor and Tower belfry/ruins await dedicated art. These are background slots, not foreground solid props. Do not place opaque obstacles across traversable areas without an explicit gameplay collision change.
