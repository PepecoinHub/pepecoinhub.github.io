🖼️ Pepe Pictures ranked

  • The weekly game night, run by a host. After a 3-2-1 countdown a picture appears as a few giant pixels and gets sharper and sharper.
  • Type the answer in the chat. The first 3 correct guesses score 3 / 2 / 1 points (some nights only the winner scores, and the last question can be worth more).
  • Counts for the season leaderboard. Top 3 of every season go to the Hall of Fame.
