Season points come from the weekly Guess the Picture nights. First 3 correct guesses score 3 / 2 / 1 points. Ties go to more 1st places, then more 2nd places, then to whoever got there first. Draw & Guess is just for fun: its scores only last until the end of each game.

✓ verified = logged in with Discord (nickname reserved). guest = points are tracked by nickname, so someone else could play under the same name.
