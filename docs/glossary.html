Pepecoin glossary

The words that keep coming up around PEP, each in a sentence or two, with a link to where this site goes deeper.

Terms

AuxPoW Block Block explorer Block reward Cold wallet Custodial Difficulty ERC-20 Fair launch Full node Halving Hashrate Inflation rate Market cap Mining pool Premine Proof of work Recovery phrase Scrypt UTXO
AuxPoW (merged mining)
Auxiliary proof of work. One piece of mining work counts on several chains that use the same algorithm, and each chain pays its own reward. PEP has used it with Litecoin and Dogecoin since block 42,000. The Scrypt family →
Block
A batch of transactions added to the chain. Pepecoin aims for one block every 60 seconds. Network stats →
Block explorer
A website that shows blocks, transactions and address balances, such as PepeBlocks or Pepeplorer for PEP. How to buy PEP →
Block reward
The new coins paid to whoever mines a block. 10,000 PEP since block 600,000. Supply and inflation →
Cold wallet
A wallet whose keys stay off internet-connected computers, such as a Tangem card. Wallets for PEP →
Custodial
Someone else, usually an exchange, holds the keys and the coins for you. Wallets for PEP →
Difficulty
How hard it is to find a valid block. It adjusts so blocks keep arriving about once a minute. Hashrate compared →
ERC-20
The token standard on Ethereum. PEPE and PEPECOIN are ERC-20 tokens; PEP is not. Which is which →
Fair launch
A start with no premine, presale or team allocation, where every coin comes from mining. PEP launched this way. Which is which →
Full node
Software that downloads and checks every block itself, such as Pepecoin Core. Wallets for PEP →
Halving
A cut of the block reward by half. PEP's reward halved every 100,000 blocks until block 600,000 and has stayed at 10,000 since. Supply and inflation →
Hashrate
The total computing power mining a chain, in hashes per second. PEP's was about 2.9 PH/s in October 2026. Hashrate compared →
Inflation rate
New coins per year divided by the coins that exist. For PEP about 5% in 2026, falling every year. Supply and inflation →
Market cap
Price times supply. Useful for comparing the size of two coins. PEP and DOGE →
Mining pool
A service where many miners combine their work and share the rewards. How to mine PEP →
Premine
Coins created for insiders at launch, outside normal mining. PEP had none. Which is which →
Proof of work
Security through computing work: miners compete to find the next block, and changing history would mean redoing that work. The Scrypt family →
Recovery phrase
A list of words that backs up a wallet’s keys. Whoever has it can spend the coins. Wallets for PEP →
Scrypt
The hashing function behind Litecoin, Dogecoin and Pepecoin, published by Colin Percival in 2009. It needs more memory than Bitcoin’s SHA-256. The Scrypt family →
UTXO
Unspent transaction output. Coins exist as outputs that can each be spent once. Bitcoin, Dogecoin and Pepecoin work this way; Ethereum tokens keep balances instead. Which is which →
