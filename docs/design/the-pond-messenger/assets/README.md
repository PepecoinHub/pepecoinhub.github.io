# Reusable original SVG UI icons
48x48 viewBox with 1998–2003 beveled/pixel-ish style; intentionally simple and lightweight.
- messenger.svg — desktop / title icon
- frens.svg — friends list
- passport.svg — profile
- noticeboard.svg — news pin board
- add-fren.svg — request
- bell.svg — notices/mentions
- online.svg — online indicator
- present.svg — optional future small gift (not functional or unlocked yet)

All icons have explicit xmlns, viewBox, role=img, title and no remote dependencies.
These are starter UI assets, **not** final Pepe avatar art: for avatar use approved PR #191 layers.
