Common questions

How do I verify PEP when withdrawing?

Pick Pepecoin (PEP) on the Pepecoin network. The receiving address must start with P, not 0x. PEPE and PEPECOIN are Ethereum tokens. See Which Pepecoin is which? and How to buy PEP.

Are wrong-network sends recoverable?

Usually not. Always match ticker, network and address format before sending. Check PEP transfers on PepeBlocks or Pepeplorer.
