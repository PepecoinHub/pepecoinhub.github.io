# PepeGochi A19: froglet care graphics

Draft review only; no merge or deployment without approval. Stacked on A18 (#360).

The froglet's cleaning cycle uses four refined replacements matching A16's approved froglet: soap, lather, bubbles, sparkle. The source character retains its familiar blue hoodie, green face and tail. Each replacement is a 128 × 128 RGBA PNG with binary alpha; feet remain at y=124. The floating bubbles are included in the third frame's bounding box. No gameplay, SQL, animation timing or care rewards are changed.

`clean.png` shows the four frames in order. Art generated using the A16 master as the style reference and the old individual frame as the action/placement reference, then normalized to the native sprite canvas.
